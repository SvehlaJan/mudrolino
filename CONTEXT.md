# Mudrolíno

A local-first learning app of short mini-games for preschoolers who cannot read
yet. This glossary covers how a child moves through the app.

## Language

**Home screen**:
The screen that lists every game as a Game card; the place a child returns to between games.
_Avoid_: Home (for anything inside a game), menu, main screen

**Game card**:
A tile on the Home screen that stands for one game; tapping it starts a Session of that game.
_Avoid_: Game tile, game button

**Unplayable**:
Said of a game whose current content and Game settings leave nothing to ask; its Game card is dimmed, says why, and starts nothing.
_Avoid_: Unavailable, disabled, locked

**Session**:
One run of a game from its first Round to the Completion screen; it only ever starts from a tap on a Game card or on play again.
_Avoid_: Game (for a single run), level

**Completion screen**:
The screen that ends a Session, offering to play again or go back to the Home screen.
_Avoid_: Session complete overlay, end screen, game over

**Round**:
One Prompt and the child's answers to it, until it is resolved.
_Avoid_: Turn, question

**Prompt**:
What a Round says aloud to set the task, usually an instruction phrase followed by the target; the only instruction a child gets.
_Avoid_: Question, lobby instruction

## Adults

**Parent area**:
The part of the app, behind the Parent gate, where adults change settings and content.
_Avoid_: Parent zone, settings (for the whole area), dashboard

**Parent gate**:
The arithmetic check an adult solves to enter the Parent area.
_Avoid_: Lock, PIN

**Game settings**:
The options an adult chooses for one game, reached only through the Parent area.
_Avoid_: Lobby settings
