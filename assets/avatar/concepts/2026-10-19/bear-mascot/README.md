## Generation brief

One three-column comparison sheet of original bear companions for a Slovak/Czech
preschool learning app. Gentle, patient, gender-neutral caregiver character;
honey-brown bear, lighter muzzle, round ears, gentle eyebrows/eyes and a warm
closed-mouth smile. All wear the same cornflower-blue crew-neck shirt, navy
trousers and blue/ivory sneakers, drawn from the existing palette-A wardrobe.

Use rounded matte stylized 3D forms, soft studio lighting, warm ivory background,
equal-height full-body three-quarter views and a face close-up for each option.
Label only A/B/C. A is a plush teddy with short limbs; B balances cuddly bear and
gesturing companion proportions; C has longer humanlike limbs and a bear head.
Avoid baby styling, stern teacher styling, realistic fur, sharp teeth/claws,
props, branded cartoon likenesses and extra accessories. Treat this as an
appearance comparison; clothing compatibility requires actual model checks.
