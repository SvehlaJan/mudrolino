## Reading older records

Specs capture the intended behavior at the time; plans capture proposed implementation steps; handoffs capture delivered work and bounded verification. Later decisions can supersede any of them. Use their revision, scope and reported result when citing evidence; a historical passing run is not fresh verification of today's code.

Completed redesign phase records and retired modular-avatar experiments remain available in their original directories.
